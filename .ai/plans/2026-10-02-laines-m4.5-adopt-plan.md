# L.AI.nes M4.5 — `adopt` and `ai sync` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `laines adopt <dir>` turns an existing git checkout into a container with the original folder as `lane_1` (nothing re-cloned, nothing lost), the project's `.ai/` becomes the container's shared layer (also seeded by `init` when the remote commits `.ai/`), and `laines ai sync <lane>` moves knowledge between the container and a lane's committed `.ai/` with a three-way comparison so it can travel in PRs.

**Architecture:** A pure-ish library (`src/lib/ai-tree.js`) defines the synced set, walks `.ai/` trees without following symlinks, copies trees, plans a three-way sync, and stores the base in `.laines/ai-sync.json`. `ai sync` is a registry command gated by a new `aiSync` capability, exposed on the CLI and over MCP. `init` seeds through `src/lib/ai-seed.js` (a blob-less shallow clone into a temp dir). `adopt` (`src/commands/adopt.js`) checks, moves the folder with two renames, reuses `init`'s `writeContainer`, registers the lane (the commit point: any earlier failure rolls back exactly), then writes lane files.

**Tech Stack:** Node ≥ 20 (ESM), commander 12, zod 4, vitest 4, `@modelcontextprotocol/sdk` ^1.32, system `git`, the bundled dot-ai CLI.

**Spec:** `.ai/plans/2026-10-02-laines-m4.5-adopt-design.md` (approved design; wins over the v1 spec where they differ) and `.ai/plans/2026-09-29-laines-spec.md`.

**Verified before writing (do not re-litigate):**
- `dot-ai init` on an existing `.ai/` is additive: existing files, folders and custom README text are kept; only missing scaffold is added. So adopt seeds `.ai/` first and then calls the same `writeContainer` as `init`.
- `git clone --depth 1 --filter=blob:none --no-checkout --branch <b> -- <remote> <dir>` then `git checkout HEAD -- .ai` materialises only `.ai/` (local-path remotes print "ignored" warnings and still work). `git ls-tree -r --name-only -z HEAD -- .ai` is empty when the remote commits no `.ai/`.
- `git ls-remote --exit-code --heads origin` exits `0` with branches, `2` for an empty remote, other codes for unreachable.

**Decisions made while planning (recorded for review):**
- **adopt's commit point is the lane's registration in `lanes.json`.** Everything before it (move, `.ai/` copy, container files, machine-index claim) rolls back exactly; lane-local files, `.pre-laines` backups and the removal of untracked `.ai/` files happen *after* it, so rollback never touches the project's own files. A failure after the commit point keeps the container and says to run `laines refresh <lane>`. (The design put the commit point after lane files; moving it earlier is what makes the rollback exact.)
- **Laines-owned container files are not synced:** `runbooks/lane-management.md`, `templates/lane-{ai-readme,context-readme,plans-readme,local-instructions}.md`, and everything under `archive/` (laines writes board-log overflow and torn-down lanes' plans there). Known limitation: the dot-ai folder READMEs that index them (`runbooks/README.md`, `templates/README.md`) do sync, so a repo can gain index rows for files it lacks; reviewers see it in the PR.
- **Sync scope is the whole synced set (user's call, 2026-10-02).** The first `ai sync` into a repo that commits only part of `.ai/` (e.g. `knowledge/`) also brings the container's dot-ai scaffold into the lane (~12 files: folder READMEs, `.gitignore`), and so into the next PR. Consequently `doctor`'s "full .ai/ layer was scaffolded in the lane" check is skipped for a repository that commits `.ai/`.
- **`adopt` joins the human-only commands** (deny rules). Containers made before M4.5 lack its rules, so `refresh` now also merges the container's deny rules, and `doctor` says so.
- **Seeding temp dir:** under the machine config dir (`<configDir>/seed-*`, as the design says), removed in `finally`; per-test config dirs keep tests from seeing each other's temp dirs.
- **Test fixtures:** `testDeps.gitAsync` fails clones of `example.com` fixture remotes at once, so tests that `init` with a fake remote never wait on the network.

## Global Constraints

- Everything in the M1–M4 plans' Global Constraints still applies (Node `>=20`, ESM, exit codes `0/1/2/3/4`, JSON by default with `--format table`, `--dry-run` a true no-op, commands return data and never print, `readJson`/`writeJson`/`writeFileAtomic` for files, every `lanes.json` change through `updateLanes`, git only through `deps.git`/`deps.gitAsync`, every command through the registry's `invoke`, MCP tools declare no `force`/`prune`/`container`, board requests via `putRequest`/`dropRequests`, conventional commits staged by explicit path).
- **Never follow a symlink** inside `.ai/` when walking, copying or syncing; symlinks are reported and skipped.
- **`ai sync` writes only inside `<container>/.ai/` and `<lane>/.ai/`**, after `assertLaneDir` on the lane; a conflicting file is left untouched on both sides and its base entry is not updated.
- **`adopt` never deletes or overwrites a file of the project** before the lane is registered; after registration it removes only untracked files under `<lane>/.ai/` that were already copied to the container, and renames (never overwrites) untracked lane-local collisions to `<name>.pre-laines`.
- Synced set (design §4.3): regular files under `.ai/` except `context/**`, `plans/**`, `archive/**`, any path segment starting with `_`, `.ai/README.md`, `.ai/.lane.json`, and the laines-owned container files listed above.

## Review Focus

1. **A project path with spaces, or adopt given a symlink to the project** — the container lands at the real path and every hint is shell-quoted. Task 4 pins it.
2. **Detached HEAD, or no `origin/HEAD` ref** — the lane records the default branch (from `origin/HEAD`, else the current branch, else `main`) instead of failing. Task 4 pins it.
3. **Running `ai sync` twice in a row** — the second run is a no-op (nothing moves, no board line, base unchanged). Task 2 pins it.
4. **A symlink (file or directory) inside `.ai/`** — never followed, never deleted on the other side, reported; adopt warns, sync lists it under `refused`. Tasks 1 and 2 pin it.
5. **A container made before M4.5 (no `ai-sync.json`, no `adopt` deny rule)** — the first `ai sync` merges both sides (files on one side only move across; files differing on both sides are conflicts); `refresh` adds the missing deny rules. Tasks 2 and 4 pin it.

```js
import { copyFileSync, existsSync, lstatSync, mkdirSync, readdirSync, readFileSync } from 'node:fs';
import { dirname, join } from 'node:path';
import { z } from 'zod';
import { checksum } from './hooks.js';
import { readJson, writeJson } from './jsonfile.js';
import { parseWith } from './schema.js';
import { gitOut } from './git.js';

// laines writes these into every container's .ai/: they describe the container, not the project.
const LAINES_OWNED = new Set([
  'runbooks/lane-management.md',
  'templates/lane-ai-readme.md',
  'templates/lane-context-readme.md',
  'templates/lane-plans-readme.md',
  'templates/lane-local-instructions.md',
]);

// Design §4.3: the synced set is .ai/ minus lane-owned, local-only and laines-owned paths
// (laines writes board-log overflow and torn-down lanes' plans into archive/).
export function isSynced(rel) {
  const parts = rel.split('/');
  if (parts[0] === 'context' || parts[0] === 'plans' || parts[0] === 'archive') return false;
  if (parts.some((p) => p.startsWith('_'))) return false;
  if (rel === 'README.md' || rel === '.lane.json') return false;
  return !LAINES_OWNED.has(rel);
}

// Every entry under dir as '/'-separated relative paths. Symlinks are listed, never followed.
export function walk(dir) {
  const files = [];
  const symlinks = [];
  const visit = (abs, rel) => {
    for (const name of readdirSync(abs).sort()) {
      const childAbs = join(abs, name);
      const childRel = rel ? `${rel}/${name}` : name;
      const st = lstatSync(childAbs);
      if (st.isSymbolicLink()) symlinks.push(childRel);
      else if (st.isDirectory()) visit(childAbs, childRel);
      else if (st.isFile()) files.push(childRel);
    }
  };
  if (existsSync(dir) && lstatSync(dir).isDirectory()) visit(dir, '');
  return { files: files.sort(), symlinks: symlinks.sort() };
}

export function syncedState(aiDir) {
  const { files, symlinks } = walk(aiDir);
  return {
    files: Object.fromEntries(files.filter(isSynced).map((rel) => [rel, checksum(readFileSync(join(aiDir, rel)))])),
    symlinks: symlinks.filter(isSynced),
  };
}

// Copies every regular file of src into dest; symlinks are skipped and reported.
export function copyTree(src, dest) {
  const { files, symlinks } = walk(src);
  for (const rel of files) {
    const to = join(dest, rel);
    mkdirSync(dirname(to), { recursive: true });
    copyFileSync(join(src, rel), to);
  }
  return { copied: files, skippedSymlinks: symlinks };
}

const own = (o, k) => (Object.hasOwn(o, k) ? o[k] : undefined);

// Design §4.3, per file: c = container, l = lane, b = base (undefined = absent).
export function planSync({ container, lane, base }) {
  const paths = [...new Set([...Object.keys(container), ...Object.keys(lane), ...Object.keys(base)])].sort();
  const toLane = [];
  const toContainer = [];
  const conflicts = [];
  const next = [];
  for (const rel of paths) {
    const c = own(container, rel);
    const l = own(lane, rel);
    const b = own(base, rel);
    if (c === l) {
      if (c !== undefined) next.push([rel, c]);
    } else if (l === b) {
      toLane.push(rel);
      if (c !== undefined) next.push([rel, c]);
    } else if (c === b) {
      toContainer.push(rel);
      if (l !== undefined) next.push([rel, l]);
    } else {
      conflicts.push(rel);
      if (b !== undefined) next.push([rel, b]);
    }
  }
  // fromEntries defines own properties, so a "__proto__" path stays data.
  return { toLane, toContainer, conflicts, nextBase: Object.fromEntries(next) };
}

export function aiDrift(containerAi, laneAi) {
  const c = syncedState(containerAi).files;
  const l = syncedState(laneAi).files;
  return [...new Set([...Object.keys(c), ...Object.keys(l)])].filter((rel) => own(c, rel) !== own(l, rel)).length;
}

const BaseSchema = z.strictObject({
  version: z.literal(1),
  base: z.record(z.string(), z.string().regex(/^sha256:[0-9a-f]{64}$/)),
});

export const aiSyncFile = (paths) => join(paths.laines, 'ai-sync.json');

export const readAiBase = (paths) =>
  parseWith(BaseSchema, readJson(aiSyncFile(paths), { onMissing: () => ({ version: 1, base: {} }) }), aiSyncFile(paths)).base;

export const writeAiBase = (paths, base) => writeJson(aiSyncFile(paths), { version: 1, base });

export function repoCommitsAi(deps, repoDir) {
  return gitOut(deps, ['ls-files', '-z', '--', '.ai'], repoDir)
    .split('\0')
    .some((f) => f.startsWith('.ai/') && isSynced(f.slice('.ai/'.length)));
}
```

```js
export function operationInProgress(deps, repoDir) {

}
```

```js
import { dirname, join } from 'node:path';
```

```js
import { getLane, readLanes, updateLanes } from '../lib/lanes-store.js';

function copyOrDelete(from, to) {
  if (existsSync(from)) {
    mkdirSync(dirname(to), { recursive: true });
    writeFileAtomic(to, readFileSync(from));
  } else {
    rmSync(to, { force: true });
  }
}

const without = (files, refused) =>
  Object.fromEntries(Object.entries(files).filter(([rel]) => !refused.some((s) => rel === s || rel.startsWith(`${s}/`))));

// Design §4.3: an explicit three-way sync between the container's live .ai/ and a lane's committed .ai/.
export async function runAiSync(opts, deps) {
  const ctx = loadContainer(opts, deps);
  const name = laneFrom(opts, deps, ctx);
  const lane = getLane(readLanes(ctx), name);
  if (!lane) throw new InvalidInputError(`No lane named ${name}. See \`laines list\`.`);
  if (lane.state === 'closed') throw new InvalidInputError(`Lane ${name} is closed.`);
  const laneDir = join(ctx.root, lane.repos[0].path);
  const real = assertLaneDir(ctx.root, laneDir, lane.repos[0].path);
  if (!real || !existsSync(join(real, '.git'))) throw new InvalidInputError(`${laneDir} is missing or not a git clone.`);
  const empty = { dryRun: Boolean(opts.dryRun), lane: name, toLane: [], toContainer: [], deleted: { lane: [], container: [] }, refused: [], conflicts: [] };
  if (!repoCommitsAi(deps, real)) {
    return { ...empty, applies: false, note: 'This repository does not commit .ai/: knowledge stays in the container.' };
  }
  const op = operationInProgress(deps, real);
  if (op) throw new BlockedError(`Lane ${name} has a git operation in progress (${op}). Finish or abort it, then run \`laines ai sync ${name}\`.`);
  const laneAi = join(real, '.ai');
  if (lstatSync(laneAi).isSymbolicLink()) throw new BlockedError(`${laneAi} is a symbolic link: refusing to sync through it.`);

  const c = syncedState(ctx.paths.ai);
  const l = syncedState(laneAi);
  const refused = [...new Set([...c.symlinks, ...l.symlinks])].sort();
  const base = readAiBase(ctx.paths);
  const plan = planSync({ container: without(c.files, refused), lane: without(l.files, refused), base: without(base, refused) });
  const keptBase = Object.entries(base).filter(([rel]) => !Object.hasOwn(without({ [rel]: 1 }, refused), rel));
  const nextBase = Object.fromEntries([...Object.entries(plan.nextBase), ...keptBase]);
  const result = {
    ...empty,
    applies: true,
    toLane: plan.toLane,
    toContainer: plan.toContainer,
    deleted: {
      lane: plan.toLane.filter((rel) => !Object.hasOwn(c.files, rel)),
      container: plan.toContainer.filter((rel) => !Object.hasOwn(l.files, rel)),
    },
    refused,
    conflicts: plan.conflicts,
  };
  if (opts.dryRun) return result;

  for (const rel of plan.toLane) copyOrDelete(join(ctx.paths.ai, rel), join(laneAi, rel));
  for (const rel of plan.toContainer) copyOrDelete(join(laneAi, rel), join(ctx.paths.ai, rel));
  writeAiBase(ctx.paths, nextBase);
  const moved = plan.toLane.length + plan.toContainer.length;
  if (moved || plan.conflicts.length) {
    const now = deps.now();
    const text = `.ai/ synced: ${plan.toLane.length} to the lane, ${plan.toContainer.length} to the container${plan.conflicts.length ? `, ${plan.conflicts.length} conflict(s)` : ''}`;
    await updateLanes(ctx, deps, (state) => ({ state, result: null, activity: [{ ts: now, lane: name, text }] }));
    appendAudit(ctx.paths.audit, { ts: now, action: 'ai-sync', container: ctx.id, lane: name, toLane: plan.toLane.length, toContainer: plan.toContainer.length, conflicts: plan.conflicts.length }, { warn: deps.warn });
  }
  if (plan.conflicts.length) {
    throw new BlockedError([
      `.ai/ sync of ${name} stopped on ${plan.conflicts.length} conflict(s): changed in both the container and the lane.`,
      ...plan.conflicts.flatMap((rel) => [`  ${rel}`, `    container: ${join(ctx.paths.ai, rel)}`, `    lane:      ${join(laneAi, rel)}`]),
      'Everything else was synced. Make the two copies identical (edit the container copy to what you want, copy it over the lane copy), then run',
      `\`laines ai sync ${name}\` again.`,
    ].join('\n'));
  }
  return result;
}
```

```js
import { existsSync, mkdirSync, mkdtempSync, rmSync } from 'node:fs';
import { join } from 'node:path';
import { copyTree, syncedState } from './ai-tree.js';
import { configDir } from './paths.js';

const lastLine = (s) => String(s ?? '').trim().split('\n').filter(Boolean).pop() ?? 'unknown error';

// Design §4.1: a new container's shared .ai/ starts from the remote's default branch when it commits
// one. Only .ai/ is checked out of a shallow, blob-less clone in a temp dir under the machine config
// dir, which is always removed.
export async function seedFromRemote(deps, remote, branch, destAi) {
  const config = configDir(deps.env, deps.homedir());
  mkdirSync(config, { recursive: true });
  const tmp = mkdtempSync(join(config, 'seed-'));
  const none = { seeded: false, files: 0, base: {}, warning: null };
  const unreadable = (why) => ({ ...none, warning: `could not read the remote's .ai/ (${why}); the container starts with a fresh .ai/ layer` });
  try {
    const repo = join(tmp, 'repo');
    const clone = await deps.gitAsync(
      ['clone', '--quiet', '--depth', '1', '--filter=blob:none', '--no-checkout', '--branch', branch, '--', remote, repo],
      { cwd: tmp },
    );
    if (clone.error || clone.status !== 0) return unreadable(lastLine(clone.stderr || clone.error?.message));
    const listed = deps.git(['ls-tree', '-r', '--name-only', '-z', 'HEAD', '--', '.ai'], { cwd: repo });
    if (listed.error || listed.status !== 0) return unreadable(lastLine(listed.stderr));
    if (!listed.stdout) return none;
    const checkout = await deps.gitAsync(['checkout', '--quiet', 'HEAD', '--', '.ai'], { cwd: repo });
    if (checkout.error || checkout.status !== 0 || !existsSync(join(repo, '.ai'))) return unreadable(lastLine(checkout.stderr));
    const { copied } = copyTree(join(repo, '.ai'), destAi);
    return { seeded: true, files: copied.length, base: syncedState(join(repo, '.ai')).files, warning: null };
  } finally {
    rmSync(tmp, { recursive: true, force: true });
  }
}
```

```js
// Design §3.1: everything adopt checks before touching anything. Returns where things are.
function inspect(opts, deps) {
  if (!opts.dir) throw new InvalidInputError('Usage: laines adopt <dir>');
  const given = resolve(deps.cwd(), opts.dir);
  // The temp sibling sits next to the real folder, so look beside the realpath of the parent (adopt
  // may be given a symlink whose target has already been moved aside).
  const parent0 = existsSync(dirname(given)) ? realpathSync(dirname(given)) : dirname(given);
  const name0 = existsSync(given) ? basename(realpathSync(given)) : basename(given);
  // A crash between the two renames leaves the project in a hidden sibling: say how to put it back.
  const leftover = existsSync(parent0) ? readdirSync(parent0).find((e) => e.startsWith(tempPrefix(name0))) : undefined;
  if (leftover) {
    throw new BlockedError(
      `An earlier \`laines adopt\` of ${given} was interrupted; the project is in ${join(parent0, leftover)}.\n` +
        `Put it back (remove ${given} first if it exists and holds only a partial container):\n` +
        `  mv ${shellQuote(join(parent0, leftover))} ${shellQuote(given)}`,
    );
  }
  if (!existsSync(given) || !statSync(given).isDirectory()) throw new InvalidInputError(`${given} is not a directory.`);
  const dir = realpathSync(given);
  const home = deps.homedir();
  if (dir === parse(dir).root || (existsSync(home) && dir === realpathSync(home))) throw new InvalidInputError(`Refusing to adopt ${dir}.`);
  if (existsSync(join(dir, '.laines'))) throw new InvalidInputError(`${dir} is already a L.AI.nes container.`);
  const dotGit = join(dir, '.git');
  if (existsSync(dotGit) && !isGitDir(dotGit)) {
    throw new InvalidInputError(`${dir} is a git worktree or submodule (its .git is a file). Adopt the main checkout instead.`);
  }
  if (!existsSync(dotGit)) {
    const interrupted = existsSync(join(dir, 'lane_1', '.git')) ? `\nIf an earlier adopt was interrupted, the project may be in ${join(dir, 'lane_1')}.` : '';
    throw new InvalidInputError(`${dir} is not a git repository.\n${setupSteps(dir)}${interrupted}`);
  }
  const top = realpathSync(gitOut(deps, ['rev-parse', '--show-toplevel'], dir).trim());
  if (top !== dir) throw new InvalidInputError(`${dir} is not the root of its git repository (${top}).`);
  for (let d = dirname(dir); ; d = dirname(d)) {
    if (existsSync(join(d, '.git'))) throw new InvalidInputError(`${dir} is inside the git repository ${d}. Adopt a top-level checkout.`);
    if (existsSync(join(d, '.laines', 'container.json'))) throw new InvalidInputError(`${dir} is inside the container ${d}.`);
    if (dirname(d) === d) break;
  }
  const origin = deps.git(['remote', 'get-url', 'origin'], { cwd: dir });
  if (origin.status !== 0 || !origin.stdout.trim()) throw new InvalidInputError(`${dir} has no \`origin\` remote.\n${setupSteps(dir)}`);
  const remote = origin.stdout.trim();
  if (remote.startsWith('-')) throw new InvalidInputError(`origin URL must not start with "-" (got "${remote}").`);
  const op = operationInProgress(deps, dir);
  if (op) throw new InvalidInputError(`${dir} has a git operation in progress (${op}). Finish or abort it, then run laines adopt again.`);
  return { dir, name: basename(dir), parent: dirname(dir), remote };
}

async function assertRemoteReachable(deps, { dir, remote }) {
  const r = await deps.gitAsync(['ls-remote', '--exit-code', '--heads', 'origin'], { cwd: dir });
  if (r.status === 0) return;
  if (r.status === 2) throw new InvalidInputError(`origin (${remote}) has no branches yet: push yours first (git push -u origin <branch>), then run laines adopt again.`);
  throw new InvalidInputError(
    `Cannot reach origin (${remote}): ${lastLine(r.stderr || r.error?.message)}\n` +
      'Lanes are clones of origin, so adopt needs it reachable. Check the URL and your credentials, then run laines adopt again.',
  );
}

// Directories holding pyvenv.cfg, up to three levels down: virtualenvs store absolute paths.
function findVenvs(dir) {
  const found = [];
  const visit = (abs, rel, depth) => {
    if (depth > 3) return;
    for (const entry of readdirSync(abs, { withFileTypes: true })) {
      if (!entry.isDirectory() || entry.name === 'node_modules' || entry.name === '.git') continue;
      const childRel = rel ? `${rel}/${entry.name}` : entry.name;
      if (existsSync(join(abs, entry.name, 'pyvenv.cfg'))) found.push(childRel);
      else visit(join(abs, entry.name), childRel, depth + 1);
    }
  };
  visit(dir, '', 1);
  return found.sort();
}

  return to;
}

function plan(insp, opts, deps) {
  const { dir, remote } = insp;
  const branchNow = deps.git(['branch', '--show-current'], { cwd: dir }).stdout.trim();
  const head = deps.git(['symbolic-ref', '--short', 'refs/remotes/origin/HEAD'], { cwd: dir });
  const defaultBranch = head.status === 0 && head.stdout.trim() ? head.stdout.trim().replace(/^origin\//, '') : branchNow || 'main';
  const agents = parseAgents(opts.agents);
  const repoName = repoSlugFromRemote(remote);
  const config = buildConfig({ repoName, remote, defaultBranch, agents });
  const lane = `${config.lanePrefix}1`;
  const aiDir = join(dir, '.ai');
  const hasAi = existsSync(aiDir) && lstatSync(aiDir).isDirectory();
  const aiWalk = hasAi ? walk(aiDir) : { files: [], symlinks: [] };
  const collisions = collisionCandidates(agents).filter((f) => existsSync(join(dir, f)) && !isTracked(deps, dir, f));
  // Stash commits are not "unpushed work": they stay with lane_1 either way (same rule as lane-git.js).
  const unpushed = Number(gitOut(deps, ['rev-list', '--count', '--exclude=refs/stash', '--all', '--not', '--remotes'], dir).trim()) || 0;
  const venvs = findVenvs(dir);
  const warnings = [];
  if (unpushed) warnings.push(`${unpushed} commit(s) exist on no remote: they stay in ${lane}, but new lanes clone origin and won't have them until you push.`);
  if (venvs.length) warnings.push(`Python virtualenv(s) store absolute paths and must be recreated after the move (for uv: uv sync): ${venvs.join(', ')}`);
  if (aiWalk.symlinks.length) warnings.push(`.ai/ symbolic links are not copied to the container: ${aiWalk.symlinks.join(', ')}`);
  return {
    branch: branchNow || defaultBranch,
    agents,
    repoName,
    config,
    lane,
    ai: { mode: hasAi ? 'seed' : 'fresh', files: aiWalk.files.length },
    backups: collisions.map((f) => ({ from: f, to: backupName(dir, f) })),
    warnings,
    venvs,
  };
}

const nextSteps = (laneDir, dir, p) => [
  `cd ${shellQuote(laneDir)}`,
  ...(p.venvs.length ? [`recreate the virtualenv(s) in the lane (e.g. uv sync): ${p.venvs.join(', ')}`] : []),
  `stop dev servers started from the old path and reopen editors on ${laneDir}`,
  `Claude's saved project memory for ${dir} now belongs to the container session`,
  'create more lanes: laines create',
];

// Design §3. Human-only (deny rules). The commit point is the lane's registration: everything before
// it rolls back exactly; after it, failures keep the container and name the fix.
export async function runAdopt(opts, deps) {
  if (opts.id !== undefined) validateId(opts.id);
  const insp = inspect(opts, deps);
  await assertRemoteReachable(deps, insp);
  const p = plan(insp, opts, deps);
  const indexDir = configDir(deps.env, deps.homedir());
  const blockSize = p.config.maxLanes * p.config.ports.stride;
  const laneDir = join(insp.dir, p.lane);
  const summary = (id, portRange, ports, backups) => ({
    id, path: insp.dir, portRange, lane: p.lane, lanePath: laneDir, branch: p.branch, ports,
    remote: insp.remote, ai: p.ai, backups, warnings: p.warnings,
  });

  if (opts.dryRun) {
    const index = loadIndex(indexDir);
    const taken = index.containers.map((c) => c.id);
    if (opts.id !== undefined && taken.includes(opts.id)) throw new InvalidInputError(`Container id "${opts.id}" is already used on this machine. Pick another with --id.`);
    const portRange = allocateBlock({ range: index.machine.range, blockSize }, index.containers.map((c) => c.portRange));
    return { dryRun: true, ...summary(opts.id ?? uniqueId(p.repoName, taken), portRange, lanePorts(portRange, 1, p.config.ports.stride), p.backups), files: CONTAINER_FILES(p.agents), next: [] };
  }

  const entry = await claimContainer(indexDir, { path: insp.dir, id: opts.id, baseId: p.repoName, blockSize, now: deps.now() });
  const ports = lanePorts(entry.portRange, 1, p.config.ports.stride);
  const tmp = join(insp.parent, `${tempPrefix(insp.name)}${deps.now().replace(/[:.]/g, '-')}`);
  const moved = { aside: false, inside: false };
  const laneAi = join(laneDir, '.ai');
  let tracked = [];
  let copied = [];

  const rollback = async () => {
    const problems = [];
    const attempt = (what, fn) => {
      try {
        fn();
      } catch (e) {
        problems.push(`${what}: ${e.message}`);
      }
    };
    if (moved.inside) {
      attempt('removing the partial container', () => {
        for (const e of readdirSync(insp.dir)) if (e !== p.lane) rmSync(join(insp.dir, e), { recursive: true, force: true });
      });
      attempt(`moving ${laneDir} aside`, () => renameSync(laneDir, tmp));
      attempt(`removing ${insp.dir}`, () => rmdirSync(insp.dir));
      attempt(`restoring ${insp.dir}`, () => renameSync(tmp, insp.dir));
    } else if (moved.aside) {
      attempt(`removing ${insp.dir}`, () => existsSync(insp.dir) && rmdirSync(insp.dir));
      attempt(`restoring ${insp.dir}`, () => renameSync(tmp, insp.dir));
    }
    try {
      await releaseContainer(indexDir, entry.id);
    } catch (e) {
      problems.push(`releasing the machine-index entry: ${e.message}`);
    }
    if (!isGitDir(join(insp.dir, '.git'))) problems.push(`${insp.dir} was not restored`);
    return problems;
  };

  try {
    renameSync(insp.dir, tmp);
    moved.aside = true;
    mkdirSync(insp.dir);
    renameSync(tmp, laneDir);
    moved.inside = true;
    let base = null;
    if (p.ai.mode === 'seed') {
      // Copy, never move: the project's files are untouched until the lane is registered.
      ({ copied } = copyTree(laneAi, containerPaths(insp.dir).ai));
      tracked = gitOut(deps, ['ls-files', '-z', '--', '.ai'], laneDir).split('\0').filter(Boolean);
      const trackedSet = new Set(tracked);
      base = Object.fromEntries(Object.entries(syncedState(laneAi).files).filter(([rel]) => trackedSet.has(`.ai/${rel}`)));
    }
    writeContainer({ path: insp.dir, entry, config: p.config, agents: p.agents, deps });
    if (base) writeAiBase(containerPaths(insp.dir), base);
    const ctx = loadContainer({ container: insp.dir }, deps);
    const now = deps.now();
    await updateLanes(ctx, deps, (state) => {
      state.lanes[p.lane] = {
        number: 1,
        repos: [{ name: p.repoName, path: p.lane, branch: p.branch }],
        ports,
        state: 'active',
        status: 'idle',
        task: null,
        blocked: null,
        kept: null,
        created: now,
        updated: now,
        closed: null,
      };
      return { state, result: null, activity: [{ ts: now, lane: p.lane, text: `lane adopted from the existing checkout (branch ${p.branch})` }] };
    });
  } catch (err) {
    const problems = await rollback();
    const restored = problems.length
      ? `Rolling back was incomplete:\n${problems.map((x) => `  - ${x}`).join('\n')}`
      : `Nothing was changed: ${insp.dir} was restored as it was.`;
    throw new LainesError(`${err.message}\n${restored}`, err instanceof LainesError ? err.exitCode : 1);
  }

  // After the commit point: the container exists and the lane is registered.
  const warnings = [...p.warnings];
  try {
    for (const b of p.backups) renameSync(join(laneDir, b.from), join(laneDir, b.to));
    if (p.ai.mode === 'seed') {
      // Exactly the untracked files that were copied now live in the container's shared .ai/; tracked
      // files stay (git owns them). Then drop the folders that emptied, deepest first (never .ai/ itself):
      // an empty untracked .ai/knowledge/ would look like a stray dot-ai scaffold to doctor.
      const trackedSet = new Set(tracked);
      for (const rel of copied) if (!trackedSet.has(`.ai/${rel}`)) rmSync(join(laneAi, rel), { force: true });
      const dirs = [...new Set(copied.flatMap((rel) => rel.split('/').slice(0, -1).map((_, i, parts) => parts.slice(0, i + 1).join('/'))))];
      for (const rel of dirs.sort((a, b) => b.split('/').length - a.split('/').length)) {
        const abs = join(laneAi, rel);
        if (existsSync(abs) && readdirSync(abs).length === 0) rmdirSync(abs);
      }
    }
    const ctx = loadContainer({ container: insp.dir }, deps);
    writeLaneFiles(ctx, deps, { name: p.lane, number: 1, laneDir, branch: p.branch, ports });
    const busy = await deps.busyPorts(ports);
    if (busy.length) warnings.push(`lane ports already in use: ${busy.join(', ')}`);
  } catch (err) {
    throw new LainesError(
      `${err.message}\nThe container was created and ${p.lane} registered, but setting up the lane failed part-way. ` +
        `Fix the cause, then run \`laines refresh ${p.lane}\` and \`laines doctor\`.`,
      err instanceof LainesError ? err.exitCode : 1,
    );
  }
  appendAudit(containerPaths(insp.dir).audit, { ts: deps.now(), action: 'adopt', container: entry.id, lane: p.lane, ai: p.ai.mode }, { warn: deps.warn });
  return { dryRun: false, ...summary(entry.id, entry.portRange, ports, p.backups), warnings, files: CONTAINER_FILES(p.agents), next: nextSteps(laneDir, insp.dir, p) };
}
```
